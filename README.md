# Carty - Менеджер Списков Покупок

Carty — это нативное Android-приложение, разработанное в качестве дипломного проекта. Приложение представляет собой удобный инструмент для создания и управления списками покупок, отслеживания купленных товаров и синхронизации данных между устройствами для авторизованных пользователей.

## ✨ Основные возможности

*   **🛒 Управление списками покупок:** Создание, редактирование названий, удаление и архивация завершенных списков.
*   **⭐ Система "Избранного":** Возможность пометить часто используемые списки (например, "Еженедельные покупки"), чтобы они всегда были под рукой.
*   **🔄 Синхронизация данных:** Полная синхронизация всех данных (списки, товары, отделы) через **Firebase Firestore** для авторизованных пользователей.
*   **👤 Два режима работы:**
    *   **Гостевой режим:** Полноценное использование приложения без регистрации. Все данные хранятся локально на устройстве.
    *   **Режим пользователя:** После регистрации/входа данные синхронизируются с облаком и доступны на любом устройстве.
*   **📚 Справочники:** Ведение личных справочников товаров и отделов для быстрого наполнения списков.
*   **🤏 Сортировка и группировка:**
    *   Ручная сортировка списков, товаров и отделов с помощью **Drag-and-Drop**.
    *   Группировка товаров по отделам внутри списка для удобной навигации в магазине.

## 🛠️ Технологический стек и архитектура

Проект построен на современных и широко используемых в индустрии технологиях и подходах.

*   **Язык:** **Kotlin** — официальный язык для разработки под Android.
*   **Архитектура:** **MVVM (Model-View-ViewModel)** в сочетании с принципами **Clean Architecture**.
    *   **Presentation Layer:** UI-логика (Fragments, ViewModels).
    *   **Domain Layer:** Бизнес-логика (не выделен в отдельный модуль для простоты, совмещен с ViewModel).
    *   **Data Layer:** Репозиторий, работа с источниками данных.
*   **UI:** **XML-верстка** с использованием **ViewBinding** для безопасной работы с View-компонентами.
*   **Асинхронность:** **Kotlin Coroutines** и **Flow** для управления фоновыми задачами и реактивными потоками данных.
*   **Локальная база данных:** **Room** (часть Android Jetpack) для надежного локального хранения данных и обеспечения оффлайн-доступа.
*   **Облачная база данных и аутентификация:**
    *   **Firebase Firestore:** для синхронизации данных в реальном времени.
    *   **Firebase Authentication:** для регистрации и входа пользователей по Email/Паролю.
*   **Навигация:** **Android Navigation Component** для управления переходами между экранами.
*   **Отображение списков:** **RecyclerView** для эффективного отображения больших объемов данных.

## 🚀 Установка

### Установка APK

Готовый к установке APK-файл можно скачать прямо из этого репозитория.

1.  Скачайте файл [**carty.apk**](./cartyDRIP.apk).
2.  Разрешите установку приложений из неизвестных источников в настройках вашего телефона.
3.  Установите скачанный файл.

### Сборка из исходного кода

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/13FANG/Carty.git
    ```
2.  Откройте проект в Android Studio.
3.  Для работы синхронизации подключите проект к вашему собственному проекту Firebase и добавьте файл `google-services.json` в папку `app/`.
4.  Соберите и запустите проект.
